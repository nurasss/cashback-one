# Demo artwork

The original sample banner and offer pictures are served from `/demo/img/` by the demo web host. The reference-screen
redesign assets live in `reference-redesign/` and are served from `/demo/img/reference-redesign/` for the local demo.
Copy both directories under the demo site's `demo/img/` path when publishing the preview.

These images are presentation placeholders for the mobile demo only. Production promotion artwork continues to come
from the admin-managed image URLs.
