1. **Запуск тестового harness (`harness_serializer.exe Mode=update`):**
   - Вывод: `ERROR: Update failed`.
   - **Причина:** В функции `UpdateExistingConfigFile` создаётся временный файл `.env.service.tmp`, на который сразу накладывается атомарный DACL `SecureFileAcl` (разрешён только `SYSTEM` и `Administrators`). Поскольку тестовый процесс запущен в консоли без повышения прав (`PrivilegesRequired=lowest`), вызов `RenameFile(.tmp, .env.service)` блокируется Windows с ошибкой Access Denied (код 5).
   - В реальном установщике `CashbackOneAgent-Setup-0.4.0.exe` задан `PrivilegesRequired=admin` (повышенный токен администратора), поэтому переименование защищённого файла выполняется успешно.
   - Запуск реального установщика в рамках данной задачи запрещён правилом *«Не ставить и не обновлять службу»*.

2. **Точная верификация алгоритма обновления на файлах:**
