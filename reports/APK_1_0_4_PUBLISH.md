## Публикация сайта

Начальная предварительная проверка завершилась ошибкой `550 SIZE not allowed in ASCII mode`: NLST переключал режим FTP после TYPE I. На сервере ничего не записывалось. Владелец после сообщения об остановке повторно поручил загрузку. Исправлен только временный локальный загрузчик: TYPE I выполняется после получения списка, перед SIZE.

Перед записью:

- Локальные размер и SHA-256 APK повторно проверены.
- Подтверждено отсутствие целевого файла, наличие прежних APK и действующего app-каталога.
- Сохранены manifest, старые index/robots/sitemap, `.htaccess` и demo index в защищённой локальной папке вне Git:

  `~/.local/share/cashback-one/backups/apk-1.0.4-20261022T174456Z-0c0f75/`

- Файлы создавались с umask 077. Секретные env и ключи в копию и Git не включались. Пустую папку от первой остановленной проверки не удаляли.

Выполнена ровно одна загрузка нового APK во временное уникальное имя внутри app/, обратное чтение по FTPS с проверкой SHA-256, проверка отсутствия целевого имени, затем rename. Финальный файл повторно прочитан по FTPS и проверен по SHA-256. Автоматических повторов, перезаписи старых APK, удаления и отката не было.

После загрузки:

- Перечень и размеры всех прежних файлов app/ сохранились, добавился только APK 1.0.4.
- `.htaccess`, `index.html`, robots, sitemap и demo index совпали с исходными SHA-256.
- APK 1.0.4 скачан полностью по HTTPS: HTTP 200, MIME `application/vnd.android.package-archive`, 51 630 551 байт, SHA-256 совпал.
