## Что нужно для сборки APK 1.0.6 (нативные шаги камеры)

`expo-camera` содержит нативный код; в существующем `mobile/android/` (в git его нет) его нет:

1. `android.permission.CAMERA` должен попасть в манифест: плагин в `app.json` добавляет его при prebuild; при ручной правке — добавить `<uses-permission android:name="android.permission.CAMERA" />` в `android/app/src/main/AndroidManifest.xml`.
2. `npx expo prebuild` **без** `--clean` (существующие правки android/ сохранить), либо ручная правка манифеста + gradle-зависимость `expo-camera` (обычно добавляется autolinking'ом Expo SDK при следующей сборке gradle).
3. Убедиться, что autolinking подхватил модуль (`npx expo config --type prebuild` / логи gradle), затем штатная сборка подписанного APK.
4. `expo prebuild --clean` не запускать (потеря ручных правок android/).

Версия приложения (`version`/`versionCode`) этой задачей не менялась — bump до 1.0.6 отдельным шагом.
