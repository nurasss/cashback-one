# Публикация лендинга Cashback One — 2026-10-22

## Итог

По прямому поручению владельца опубликован лендинг `https://cashback-qr.poscenter.kz/`.
Основная кнопка скачивает `/app/cashback-one-1.0.3.apk`; вход для бизнеса — `/admin/login`.
Backend, Windows-агент и 1С не изменялись. APK и demo не перезаписывались.

Юридические документы не утверждены. `LegalPages.tsx` сохранён в исходниках, но его маршруты, ссылки и позиции sitemap исключены из публикации. `/privacy` и `/terms` показывают публичный клиентский 404 без запросов API; это не обещание HTTP 404 на SPA-хостинге. Реквизиты и контакты не выдумывались. Такая техническая мера не является заключением о юридическом соответствии сервиса.

- В браузере публичная `/`: лендинг и обе APK-ссылки 1.0.3, вход для бизнеса, нет юридических ссылок, нет загрузки AdminRoutes и запросов к API, нет горизонтального переполнения в проверенном viewport.

- В браузере `/admin/login`: видна форма входа с логином и паролем. Неавторизованный bootstrap получил ожидаемый 401. Настоящие реквизиты не вводились; авторизованный кабинет не проверялся.

## Откат

Только по отдельному поручению: взять старый `index.html` из указанной защищённой копии, проверить его SHA-256 и вернуть по FTPS через временное имя с проверкой содержимого и финальным rename. Старые assets сохранены на сервере, поэтому для возврата прежней SPA не требуется их пересоздание. `.htaccess`, `app/` и `demo/` не трогать. Не применять mirror/delete ко всему корню и не удалять новые файлы автоматически.
