## 1. Состояние продукта

Компоненты готовы к пилоту. **Сквозные начисление/списание через настоящую Cash ещё не приняты**; запуск у реального клиента не завершён.

Схема: POSCENTER Cash → POSCENTER ONE → Windows-агент → общий VPS → приложение/админка. ONE — источник правды, агент только читает. Клиенту нужны свои база, бизнес и ключ, агент на имеющемся Windows-компьютере с доступом к ONE и COM. Отдельный Windows-сервер не обязателен; Linux VPS COM-адаптер не запускает.

Работают API `https://api.cashback-qr.poscenter.kz`, админка `https://cashback-qr.poscenter.kz`, APK **1.0.1** (versionCode **2**), EXE-служба агента **0.1.0** x86. WhatsApp-вход и появление тестовой карты на телефоне проверены пользователем. Исходники в закрытом GitHub, APK/Setup — в Releases.

Карты — строки 6–15 цифр с ведущими нулями; отрицательные балансы сохраняются. WhatsApp-кодов для списания нет, OTP только для входа. Cash передаёт движения в ONE при закрытии смены; затем синхронизация обновляет приложение.

## 5. Что осталось

1. **Cash и карта:** выяснить подключённую ONE, взять реально существующую в ней карту, показать обычный штрихкод в приложении, проверить распознавание. Нужность доработки Cash для этого формата пока не установлена.
2. **Кассовый пилот:** пользователь/кассир штатно начисляет/списывает, закрывает смену; куратор сверяет ONE → агент → облако → приложение, баланс/операции/отсутствие дублей. Самому в ONE не писать. Новые изменения установленной EXE-службой таким тестом ещё не подтверждены.
3. **Первый клиент:** его бизнес/ключ/ONE/маппинг/read-only пользователь, права LocalSystem, COM/лицензия и постоянно доступный компьютер. Тестовая `int` не является подключением клиента; не менять базу поверх прежнего состояния без процедуры миграции.
4. **Отказы:** настоящий crash/restart и потеря/возврат сети без потерь/дублей. Настроенный recovery и пустая дельта это не заменяют.
5. **Эксплуатация:** регулярные защищённые копии и восстановление, замена ранее раскрытого `loyalty_ro`, защищённый backup Android keys, `.git`/`.stfolder` в Syncthing exclusions на обеих машинах. Не считать сделанным без проверки.

Отложены Wallet (нет аккаунтов/сертификатов/issuer, кнопки скрыты), App Store/Google Play, динамический QR `C1…` в Cash, Authenticode. Открыты текст «Баланс обновляется после закрытия кассовой смены», отображение массового списания 2026-09-06, пересборка demo и обновление устаревшего WhatsApp-текста `docs/WALLET.md`.

- Исправленная подготовка читает User-секреты, валидирует настоящим AgentSettings до создания backup/config, защищает DACL до записи, удерживает lock, не принимает секреты CLI. Изолированные тесты прошли после исправления кодировок. Старые scratch/debug не запускать.
