## Решение владельца

Покупатель выбирает фото профиля из галереи. Фото хранится на сервере и видно на любом его телефоне.

Сейчас `Avatar` в `mobile/src/features/profile.tsx` — неинтерактивный круг с инициалами. Поля в БД и загрузки для покупателя нет.

   - Метаданные не должны попасть в результат. **EXIF обязан быть удалён**, в фото с телефона бывают координаты. Проверь тестом: на входе JPEG с EXIF GPS, на выходе EXIF пуст.
   - Анимация не сохраняется, только первый кадр.
3. **Хранилище.**
   - `SAFE_MEDIA_PATH_REGEX`: добавь `avatars`.
   - `maybe_cleanup_old_media_file`: перед удалением учитывай ссылки в `avatar_url`, рядом с проверкой акций и логотипов. Обнови docstring.
4. **API** в `backend/app/api/customer_app.py`, для авторизованного покупателя:
   - `POST /me/avatar`, multipart, поле `file`. Лимит `avatar_max_upload_bytes = 1_500_000` в `config.py`: общий предел Caddy 2 МБ не меняем. Превышение: `FILE_TOO_LARGE`, как в кабинете. Ответ — `ProfileResponse`.
   - `DELETE /me/avatar`, ответ `ProfileResponse`. Повторный вызов не ошибка.
   - Лимит частоты через `RateLimiter`: `avatar_upload_user_limit: int = 10`, `avatar_upload_window_seconds: int = 3600`, ключ по id пользователя. Превышение: 429 `RATE_LIMIT_EXCEEDED`. Лимит — на `POST`.
