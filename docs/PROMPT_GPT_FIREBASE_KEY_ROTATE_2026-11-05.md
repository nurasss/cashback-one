**Упало или неожиданно — СТОП и опиши, что видишь на экране; без самостоятельных обходных путей; содержимое ключей не показывать.**

Общайся по-русски.

## Контекст

Проект Firebase `cashback-one-loyalty` (Google Cloud, тот же ID проекта). Сервисный аккаунт:
`firebase-adminsdk-fbsvc@cashback-one-loyalty.iam.gserviceaccount.com`.

Закрытый ключ этого аккаунта с ID, начинающимся на **`6e66f2a7`**, случайно попал в переписку и в Telegram. Его нужно удалить и выпустить новый. Я уже вошёл в свой Google-аккаунт в этом браузере.

## Что сделать

1. Открой https://console.cloud.google.com/iam-admin/serviceaccounts?project=cashback-one-loyalty
2. Открой аккаунт `firebase-adminsdk-fbsvc@cashback-one-loyalty.iam.gserviceaccount.com` → вкладка **«Ключи» (Keys)**.
3. Перепиши мне список ключей: ID (первые 8 символов), дата создания, статус. Больше ничего не трогай на других вкладках.
4. Удали **только** ключ, ID которого начинается на `6e66f2a7`. Перед подтверждением сверь ID ещё раз. Другие ключи не удаляй. Если ключа с таким ID нет — СТОП и напиши мне.
5. Там же: **«Добавить ключ» → «Создать новый ключ» → тип JSON → «Создать»**. Браузер скачает файл в папку «Загрузки».
6. **Не открывай скачанный файл, не показывай и не копируй его содержимое**, никуда его не загружай и не прикрепляй.
7. Снова выведи список ключей: старого `6e66f2a7…` нет, есть один новый (ID первые 8 символов, дата).
8. Напиши мне **имя скачанного файла** (оно вида `cashback-one-loyalty-firebase-adminsdk-fbsvc-<ID>.json`) — только имя, без содержимого.

## Нельзя

- Создавать, удалять или менять сервисные аккаунты, роли, права IAM, проекты, биллинг, другие ключи.
- Менять настройки Firebase или Google-аккаунта.
- Выводить содержимое ключа, `private_key`, `private_key_id` целиком.
