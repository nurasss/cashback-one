## Что должно измениться и что проверить

**В отличие от прошлых обновлений `.env.service` меняется.** Установщик шифрует ключ агента и пароль 1С через DPAPI.

1. **Хеши:** `agent_state.key` и `stage0_mapping.json` побайтно прежние. Хеш `.env.service` другой — это ожидаемо.
2. **`.env.service`** — проверка **без вывода значений**. Для каждого пункта выведи только `True`/`False`:
   - есть `AGENT_API_KEY_DPAPI=` с непустым значением;
   - нет строки `AGENT_API_KEY=` с открытым значением;
   - есть `ONE_PASSWORD_DPAPI=` (или как назван параметр в 0.3.0 — по `docs/AGENT_INSTALLATION.md`);
   - в `ONE_CONNECTION_STRING` нет `Pwd=` с открытым значением;
   - число остальных строк и имена остальных переменных совпадают с бэкапом. Выведи только имена переменных, которые есть в одном файле и нет в другом.
3. **Права:** DACL `.env.service` и каталога `config` прежние (SYSTEM и Администраторы). Выведи `icacls`.
4. **Служба:**
   - `--version` → 0.3.0;
   - в логе `Starting POSCENTER Loyalty Agent v0.3.0`;
   - служба Running, тип запуска Automatic (Delayed);
   - POS-сервис выключен, порт 8765 закрыт.
5. **Циклы:**
   - в первом цикле `ONE read completed: type=cards_snapshot`: число карт как до обновления (в осмотре 05.11 было 1714 записей, `skipped_invalid_barcode=4`), `changes_to_send=0` или небольшое число — перепиши как есть;
   - `transactions_window` без ошибок;
   - heartbeat успешен. Ключ из DPAPI читается — значит, облако приняло запрос: нет 401 и `AGENT_KEY_*`.
6. **СТОП и сразу сообщить:**
   - ошибка чтения конфигурации или DPAPI;
   - 401/403 от облака;
   - ошибка подключения к 1С;
   - `422`, `CloudNonRetryableError`, `CLOUD_*`, `Unexpected sync error`, Traceback;
   - служба не стартовала.
7. `status` (через владельца): курсоры `set`, `Last Error: (none)`.
8. Ждать не меньше 12 минут, минимум два цикла.
9. **Автозапуск:** перезагружать **не нужно**. Подтвердим при следующей естественной перезагрузке.

Облако проверяет куратор: версия 0.3.0, свежий heartbeat, пустой `last_error`, число карт бизнеса `test` прежнее (1711).

## Откат (только по решению владельца или куратора)

0.2.2 не читает `*_DPAPI`. Порядок отката:
1. остановить службу;
2. Setup 0.2.2 с «Сохранить существующие настройки»;
3. **вернуть `.env.service` из папки бэкапа** с прежним DACL и сверить хеш `5EA802C7…13CB`;
4. запустить службу и проверить циклы.

`state` и `mapping` не трогать.
