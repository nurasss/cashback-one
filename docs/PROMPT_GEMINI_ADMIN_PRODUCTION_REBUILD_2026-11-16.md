## Причина пропуска проверки

Имеющийся E2E-скрипт собирает отдельный временный SPA с эфемерным API-адресом.
Его PASS не доказывает работоспособность admin/dist, который идёт на хостинг.
Хеши доказывают целостность пакета, но не правильность его конфигурации.
Новый критерий: браузерная проверка именно окончательных байтов admin/dist.

## Действия

1. Зафиксировать исходное состояние и хеши rework3; сохранить прежние артефакты и отчёты.
2. Проверить отсутствие параллельной сборки и незаявленных изменений исходников после rework3.
3. Собрать из тех же исходников следующей командой из корня репозитория:

```bash
VITE_API_BASE_URL=https://api.cashback-qr.poscenter.kz VITE_ALLOW_INSECURE_HTTP=0 npm --prefix admin run build
```

4. Запустить typecheck, lint и полный набор тестов admin; сохранить фактические результаты.
5. Создать новый манифест путей, размеров и полных SHA-256 конечного admin/dist.
6. Обслужить именно готовый admin/dist локально без новой сборки и без подмены JS или конфигурации.
7. Проверить /admin/login в чистом браузерном контексте RU/KK, desktop 1366×768 и mobile 390×844.
8. Подтвердить видимую форму входа, отсутствие CONFIG_MISSING и запрос refresh к production API по HTTPS.
9. Проверить лендинг RU/KK, загрузку ресурсов и отсутствие новых ошибок страницы или переполнения.
10. Повторно сверить хеши admin/dist после браузерных проверок; сохранить пакет без дальнейшей пересборки.

Не вводить production-пароли, не выполнять login, не сохранять данные и не менять
контент реального бизнеса. Автоматический refresh без сессии допустим; ожидаемый
401 не означает успешную авторизацию. Не выводить cookies, токены и персональные данные.
Если production API не принимает локальный Origin, зафиксировать ответ/CORS отдельно:
не менять CORS/backend и не объявлять успешной интеграцию. Для проверки интерфейса
можно отдельно перехватить точный HTTPS endpoint и вернуть явно обозначенный MOCK 401.
Не путать такой сценарий с настоящим production-запросом. URL до перехвата должен
быть настоящим production URL из окончательного бандла, не переопределённым в браузере.

Один поиск домена в JS недостаточен: сохранить браузерный сетевой журнал с URL,
методами и статусами без секретных заголовков, снимки формы и ошибок консоли.
Не запускать старый E2E повторно ради доказательства новой конфигурации: его
временная сборка не заменяет проверку окончательного пакета.
