## Результат

Довести существующие локальные исправления, не переделывать уже принятое:

1. Карточки: иконки справа сверху, согласованные отступы, верхнее выравнивание текста,
   кнопки по его левому краю. Проверить страницу целиком, а не один CSS-класс.
2. Даты: работающие «Назад» и повторный клик «Обзор»/«Главная», фильтры доступны при ошибке,
   правильные даты и понятный предел из `/admin/me`.
3. Формы статусов/акций по исходным макетам, без периода/приоритета в UI и payload,
   без потери существующих остальных полей/прав/переводов. PDF не добавлять по примеру имени файла.
4. Аватар бизнеса, favicon, UTC+5, поиск и по 7 строк с достижимой остальной выдачей.
5. Все применимые формы: убрать лишние нижние «Закрыть», крестик, доступная клавиатура,
   одинаковые отступы/уровень действий, нет ненужной двойной прокрутки или обрезки контента.
   Действие «Закрыть и удалить ключ» обработать отдельно: не потерять очистку одноразового секрета.
6. Лендинг: убрать только дублирующую кнопку у входа, в RU/KK единые «бонусы», Roboto,
   белый на красном, максимум Bold, правильная иконка, убрать устаревшую пометку об iPhone
   в видимых местах/FAQ, не обещая существующий iOS-релиз.
7. Проверить обновление каталога после сохранения: API/version/ETag и получаемый приложением
   ответ. Личный уровень по обороту не выдавать за ту же функцию.
