## Что сделать

### 1. `POST /pos/code-push`

Авторизация — как у `/pos/redemptions` (`X-Pos-Key`, `app/services/pos_auth.py`; ключ даёт `business_id`). Реализация — по образцу `request_pos_redemption` в `app/services/pos_service.py`.

Тело: `{"phone": "77011234567", "code": "4554"}`.
- `phone` — строка, нормализовать `app/core/phone.py::normalize_phone` (принимать `77…`, `+77…`, `87…`); ошибка → 400 `VALIDATION_ERROR`.
- `code` — строго `^\d{4}$`, иначе 400 `VALIDATION_ERROR`. Произвольный текст от кассы **не принимать**: текст уведомления формирует сервер.

Порядок проверок:
1. push выключен → 503 `PUSH_NOT_CONFIGURED`;
2. покупатель с этим телефоном (не удалён) **и** его карта в бизнесе ключа (`UserCard` → `Card.business_id == pos_key.business_id`). Нет пользователя или нет такой карты → 404 `CARD_NOT_FOUND` (не раскрывать, что пользователь существует). Несколько карт — взять любую незаблокированную; все заблокированы → 409 `CARD_BLOCKED`;
3. нет активного устройства приложения этого бизнеса или общего (`has_active_device(..., business_id=…)`) → 409 `CUSTOMER_NO_APP`;
4. лимит — те же настройки, что у `/pos/redemptions` (5 за 10 минут на карту), → 429 `RATE_LIMIT_EXCEEDED`;
5. отправка `send_to_user(..., business_id=pos_key.business_id)`; 0 доставок или исключение → 503 `PUSH_DELIVERY_FAILED`.

Уведомление: заголовок «Код для списания бонусов», текст «Ваш код для списания бонусов: 4554 в «<название бизнеса>». Назовите его кассиру, только если сейчас оплачиваете покупку.» (без суммы — касса её не передаёт). `data = {"type": "redemption_code", …}`.

Запись в ленту уведомлений и **скрытие кода через 5 минут** — как у существующих кодов: создать `RedemptionCode` (статус `pending`, `expires_at` = сейчас + `redemption_code_ttl_seconds`, `code_hash` — хеш присланного кода тем же `_hash_code`) и `Notification` с `redemption_id`. Сумма: в `RedemptionCode.amount` NOT NULL — записать `0`; тогда `redemption_inactive_text` и все места, где показывается сумма кода (`content_service.py` ~строки 210–230, текст при `superseded`), при `amount == 0` должны выводить текст **без суммы** (например «Код больше не действует.»). Предыдущие `pending` по карте → `superseded`, как сейчас.

Ответ 200: `{"status": "sent", "expires_at": "<ISO>"}`. Ни телефон, ни код в журнал не писать (ни в INFO, ни в ошибках).
