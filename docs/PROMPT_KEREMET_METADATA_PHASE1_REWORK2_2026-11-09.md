Закрыть воспроизведённые замечания:

1. **DPAPI не попадает в соединение.** При существующей ONE_CONNECTION_STRING без Pwd расшифрованный ONE_PASSWORD_DPAPI сейчас игнорируется. Проверить действующий agent/config.py (inject_1c_password и конфликтующие варианты). Безопасно и корректно собирать строку с экранированием кавычек, проверять конфликтные способы задания. Не печатать строку/пароль. Не расшифровывать облачный ключ ради инспекции. Отдельные тесты именно аргумента Connect с синтетическими значениями: существующая строка + DPAPI, кавычки в пароле, конфликт, ошибка decrypt. COM mock подставлять НИЖЕ сборки строки, чтобы тест не обходил проверяемую логику.
2. **Неожиданные ошибки не равны отсутствию объекта.** По возможности использовать штатный безопасный поиск коллекции метаданных, отличающий ненайденный объект от ошибки обращения; подтверждать API по текущей документации. При access denied/неожиданной ошибке вернуть metadata error, ненулевой exit и прекратить обход. Тесты должны проверять, что к следующей коллекции не обращались. Не классифицировать любое исключение без слова access как NOT_FOUND.
3. **Timeout сейчас оставляет живой worker.** Семь текущих тестов этого не проверяют. Сделать ограничение жизненного цикла СВОЕГО инспектора реальным и проверить отдельным subprocess-тестом с зависающим mock. Можно использовать собственный дочерний процесс/одноразовый CLI, если остановка действует только на этот процесс и не раскрывает секреты через CLI, env или файлы; не завершать службу, процессы 1С и чужие процессы. Если остановка COM на стороне ONE не гарантируется — честно написать; «истинное прерывание потока» не обещать. Не копировать секреты в параметры запуска. Если безопасный вариант не готов — оставить блокер вместо инструкции запуска.
4. **Конфиг и база.** Не применять strip кавычек к dotenv-значениям. Подготовить совместимую со штатным конфигом загрузку без env overrides и без локального .env; x86/Python/pywin32/права проверить до COM. Нужен явный локальный барьер выбора Keremet, чтобы стандартный путь ProgramData на чужом ПК не подключил test. Не передавать пути/имя пользователя/пароль базы куратору. Использование настоящих секретов в тестах запрещено.
5. **Каталог отчётов.** Микросекунды/случайный суффикс и exclusive создание, не exist_ok=True для фиксированного имени. Два запуска при одинаковом времени должны сохранить два отчёта. Ошибки записи отчёта должны давать безопасный код, не необработанный traceback и не ложный успех.
6. **Полнота метаданных.** Фиксированные угадываемые имена не являются инвентаризацией. Ограниченно перечислять реальные имена объектов в целевых коллекциях с указанием лимита/усечения; подробности полей только релевантных объектов. Никаких запросов записей. Отсутствие совпадения в урезанном наборе не объявлять отсутствием источника.
7. **Отчёт.** Убрать «нагрузка нулевая», «утечка исключена на 100%», «полностью отработано» без доказательств. Восстановить историю первой ошибки pytest и неудачных ruff по сохранившемуся выводу; если сырой вывод потерян — честно указать. Не считать отсутствие установленного ruff успешным lint.
