# Промпт исполнителю (Windows): чистая установка агента 0.3.0 у КеремЕт — 2026-11-05

Ты работаешь на **компьютере КеремЕт** — там, где открыта база 1С КеремЕт и до сих пор стоял агент 0.1.0. Это не `KONS2`. PowerShell без повышения прав; шаги **[ВЛАДЕЛЕЦ]** выполняет владелец в админ-PowerShell по одной команде, ты ждёшь вывод. Общайся и пиши отчёт по-русски.

**Упало или неожиданно — СТОП и сырой вывод; без самостоятельных исправлений; секреты и ПДн скрыть.**

## Почему

Агент 0.1.0 здесь работал с ключом бизнеса `test` и отправлял данные КеремЕт в чужой бизнес. Владелец его остановил (служба `Stopped`, `Manual`). В облаке есть отдельный бизнес `keremet` (пустой). Нужен новый агент 0.3.0 с ключом `keremet`.

Старое состояние агента (`agent_state.db`, курсоры) считает, что всё уже отправлено. С ним `keremet` останется пустым, а установщик 0.3.0 смену ключа при существующем `agent_state.db` запрещает. Поэтому установка **с нуля**: старую папку агента **переносим в копию, не удаляем**.

1С КеремЕт — настоящая база клиента: **строго только чтение**, не открывать иначе как агентом и `check-one`.

## Шаги

1. **Компьютер:** имя, версия Windows, свободное место на C:. 1С: версии в `Program Files\1cv8`, зарегистрирован ли `V83.COMConnector` (только чтение реестра). Путь к базе 1С — только сам путь, базу не открывать.
2. **Служба:** `Get-Service POSCENTERLoyaltyAgent | Select Status, StartType` — ожидается `Stopped`, `Manual`. Иначе СТОП. Версия установленного EXE. Других процессов агента нет (`Get-CimInstance Win32_Process`, фильтр по `CashbackOneAgent`/`poscenter_loyalty_agent`).
3. **Setup 0.3.0:** владелец приносит файл с `KONS2` (`C:\cashback-stage0\agent-0.3.0\CashbackOneAgent-Setup-0.3.0.exe`) в `C:\cashback-stage0\agent-0.3.0\`. Размер **14 870 894** байта, SHA-256 `bc524cccac61ac9974e67cda8b9d2d4ed8143bc4f232f6d61fc2f396ce11be16`. Не совпадает — СТОП.
4. **[ВЛАДЕЛЕЦ] Перенос старой папки:**
   - полная копия `%ProgramData%\POSCENTER\LoyaltyAgent\` в `C:\cashback-stage0\backup_keremet_0_1_0_<yyyyMMdd_HHmmss>\` с сохранением прав (`robocopy /E /COPYALL /DCOPY:DAT`); сверь число файлов и SHA-256 каждого файла копии и оригинала (вывести только имена и совпадение `True/False`);
   - затем **переименовать** `%ProgramData%\POSCENTER\LoyaltyAgent` в `LoyaltyAgent.old-0.1.0-<yyyyMMdd_HHmmss>` (не удалять).
   - Отдельно скопируй `mapping\stage0_mapping.json` из копии в `C:\cashback-stage0\agent-0.3.0\stage0_mapping.json` и покажи SHA-256. Сравни с эталоном KONS2 `F8FEC8DB…D083` (полный хеш — в `reports/AGENT_UPGRADE_0_2_2_2026-10-24.md`). Не совпадает — СТОП, не продолжать.
5. **[ВЛАДЕЛЕЦ] Ключ:** в кабинете (`/admin`, раздел агентов) создать агента для бизнеса **`keremet`**. Ключ показывается один раз — владелец вставляет его сам в установщик и хранит у себя. **Ключ не вводить в чат, не записывать в файлы и отчёт.**
6. **[ВЛАДЕЛЕЦ] Установка** `CashbackOneAgent-Setup-0.3.0.exe` по `docs/AGENT_INSTALLATION.md`, раздел 1 «Новая установка»:
   - URL облака `https://api.cashback-qr.poscenter.kz`;
   - ключ — новый ключ `keremet`;
   - база 1С КеремЕт, пользователь и пароль — те же, что были у 0.1.0 (владелец знает; не печатать);
   - **«Проверить подключение»** до «Далее», сообщение установщика переписать как есть. Ошибка — «Отмена», СТОП;
   - маппинг — файл из шага 4.
   Если установщик пишет о существующих настройках или `agent_state.db` — СТОП (значит, папка не перенесена).
7. **Проверка после установки** (как в `docs/PROMPT_AGENT_UPGRADE_0_3_0_2026-11-05.md`, пункты 2–7, но хеши `.env.service`/`agent_state.key` новые — их только вывести):
   - `.env.service`: `AGENT_API_KEY_DPAPI` и `ONE_PASSWORD_DPAPI` есть, открытых ключа и пароля нет (`True/False`);
   - `icacls` каталога `config` и `.env.service`: только SYSTEM и Администраторы;
   - служба Running, Automatic (Delayed), `--version` 0.3.0, в логе `Starting POSCENTER Loyalty Agent v0.3.0`, порт 8765 закрыт;
   - первый цикл: `ONE read completed: type=cards_snapshot`, число записей, `skipped_invalid_barcode=…` (с причинами), `Cards ACK received: … created`; `transactions_window` без ошибок; heartbeat без 401;
   - СТОП: ошибка DPAPI/конфигурации, 401/403, ошибка 1С, `422`, `CloudNonRetryableError`, `CLOUD_*`, `Unexpected sync error`, Traceback.
   - Подожди не меньше 15 минут: первая выгрузка операций может быть большой. Перепиши строки ACK по операциям.
8. `status`: курсоры `set`, `Last Error: (none)`.

Облако проверяет куратор: агент `keremet` версии 0.3.0, карты и операции в `keremet`, у `test` один heartbeat в минуту.

- Печатать `.env.service`, ключи, пароль и строку подключения 1С, номера карт, телефоны, имена.
- Менять конфигурацию 1С, создавать в ней что-либо.
- Включать POS-сервис.
