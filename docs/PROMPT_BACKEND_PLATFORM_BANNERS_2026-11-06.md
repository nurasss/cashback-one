## Контекст

Папка `/Users/nuras/Desktop/cashback-one`, `backend/`. Задача I выкачена (коммит `0b9aae4`, alembic `0016`): приложение клиента (например KeremEt) запрашивает `/me/promotions?business_id=<бизнес клиента>`.

В кабинете суперадмин может создать баннер с аудиторией «Все бизнесы» (`promotions.business_id IS NULL`, `admin/src/pages/ContentPage.tsx`, `GLOBAL`). Это наша реклама POSCENTER / Cashback One.

Сейчас в `backend/app/services/content_service.py` при заданном `business_id`:
- если у покупателя нет карты этого бизнеса — сразу пустой ответ;
- иначе только `Promotion.business_id == business_id`, общие (`NULL`) не попадают.

## Решение владельца

1. Наши баннеры показываются **в общей карусели** приложения клиента, вперемешку с баннерами магазина, по общей сортировке (`sort_order`, затем `created_at desc`, как сейчас).
2. Их видят **все вошедшие покупатели**, даже без карты этого магазина.
3. Только тип **`banner`**. Общие акции (`offer` с `business_id IS NULL`) в приложениях клиентов по-прежнему не показываются.

## Что сделать

В режиме с `business_id` (без параметра — ответ **побайтно прежний**, старые APK и общее приложение не трогаем):

- `list_promotions`: баннеры = активные (`is_active`, `starts_at`/`ends_at`, как в `_visible_promotions`) с `business_id == B` **только если у покупателя есть карта B**, плюс активные общие баннеры (`business_id IS NULL`, `kind == 'banner'`) **всегда**. Акции (`offer`) — только бизнеса B и только при карте B. `has_new` считать как сейчас (по акциям).
- `get_promotion(id, business_id=B)`: общий активный баннер открывается всегда; баннер или акция бизнеса B — только при карте B; всё остальное — тот же 404 `PROMOTION_NOT_FOUND`.
- `badges`: без изменений по смыслу (считает акции, общие баннеры на него не влияют).
- Уведомления, `/me/cards`, `/me/app-content`, push — не менять.
- Если бизнес `B` не существует или неактивен — только общие баннеры (не 404, не 500).
- Обнови `docs/CUSTOMER_API.md` (раздел про `business_id`).

## Тесты

- покупатель без карты B: `/me/promotions?business_id=B` → только общие баннеры; акции B и баннеры B не видны; `GET /me/promotions/{общий}` → 200, `GET /me/promotions/{баннер B}` → 404;
- покупатель с картой B: баннеры B и общие вместе, в порядке `sort_order`; акции только B; общий `offer` не виден;
- неактивный / просроченный / будущий общий баннер не виден;
- без параметра: ответы как до правки (существующие тесты не менять);
- баннер другого бизнеса C не виден ни в одном случае.
