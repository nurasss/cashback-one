# Период статистики: обе даты могут быть до регистрации

В админке Cashback One для всех бизнесов и обеих ролей оставь единое правило: **«С» ≤ «По» ≤ сегодня по Астане (UTC+5)**. В оба поля можно вручную ввести или выбрать в календаре любую корректную календарную дату в поддерживаемом диапазоне, включая 01.01.1970. Равные даты допустимы. Дата регистрации бизнеса не ограничивает явно заданные даты. Если по диапазону нет операций, отдай обычный результат с нулём операций.
