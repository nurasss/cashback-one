Старая legacy-пересекающаяся шкала не оправдывает новое пересечение. Явно
проверить существующий разрешённый случай правки текста/процента без смены границ.

Ошибки для UI: стабильный machine-readable reason, допустимые field paths/ID
без SQL/секретов; stale version отличать от пересечения. Старые коды не ломать.
Миграцию без доказанной необходимости не добавлять. Если она необходима — СТОП,
