## Разрешены ровно два исправления

1. `backend/migrations/env.py`: заменить `fileConfig(config.config_file_name)` на `fileConfig(config.config_file_name, disable_existing_loggers=False)`. Схему БД и файлы миграций версий не менять, новую миграцию не создавать. Не ослаблять тест caplog.
2. `mobile/tests/noCardNotice.test.tsx`: добавить `gcTime: Infinity` к `defaultOptions.queries` создаваемого в mountWith QueryClient, сохранив `retry: false`. Это только настройка теста; runtime приложения и общие фикстуры не менять. Не использовать принудительный выход Jest и не отключать assertions.

## Проверки последовательно

- Использовать проектные интерпретаторы и зависимости. Не устанавливать/обновлять среду.
- На собственном изолированном временном PostgreSQL повторить установленную диагностикой последовательность: HTTP-запрос, создающий app.access → тест миграции 0019 → unmatched-path тест. Без подмены fileConfig, внешнего диагностического плагина и изменения порядка ради обхода. Требуется успешный результат.
- Выполнить адресные PostgreSQL-тесты миграции, затем полный backend-набор с настроенным POSTGRES_TEST_URL; SQLite-пропуски не считать PostgreSQL-проверкой. Штатно остановить только свой временный кластер и записать результат.
- Выполнить noCardNotice отдельно, затем единый запуск 11 файлов: levels, keremetStatuses, flows, finalRevisions, dynamicStatuses, serverContentAndCache, components, cacheRefresh, homeArtwork, noCardNotice, keyboardLift. Требуются не только прошедшие assertions, но и самостоятельный выход с кодом 0 без предупреждения «did not exit». Записать фактическое число тестов, не подставлять прежнее число.
- Выполнить проверку типов mobile и `git diff --check` по затронутым файлам. Общий scope правок — только два файла выше и отчёт/логи. Чужие изменения не откатывать и не форматировать.

Обновить `reports/LIFETIME_TEST_DIAGNOSTICS_2026-11-12.md` разделом реализации и результатов; полные безопасные логи сохранить в `reports/lifetime-turnover-backend-2026-11-12/`. Отделить результаты после настоящих правок от прежней диагностической подмены.
