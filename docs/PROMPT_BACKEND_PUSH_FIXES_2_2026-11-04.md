## Что не так с пунктом 3

Тест `test_concurrent_push_token_registration_race` отправляет два запроса **друг за другом**. Второй находит запись и идёт по ветке обновления, ветка `except IntegrityError` не выполняется ни разу.

Куратор выполнил эту ветку временным тестом: первый `session.scalar(select(Device)...)` подменён и вернул `None`, хотя запись уже есть, поэтому вставка попала в конфликт уникального индекса. Результат — **ошибка, а не 204**:

```text
sqlalchemy.exc.StatementError: (sqlalchemy.exc.MissingGreenlet) greenlet_spawn has not been called; can't call await_() here. Was IO attempted in an unexpected place?
[SQL: SELECT users.phone, ... FROM users WHERE users.id = ?]
```

Причина: после `session.rollback()` объект `current_user` из той же сессии устарел, и обращение к `current_user.id` в ветке `except` запускает неявную загрузку из базы вне async-контекста.
