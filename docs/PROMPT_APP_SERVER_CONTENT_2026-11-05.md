## Задача

### 1. Тексты и магазины

- Бизнес — бизнес **активной карты** (`useActiveCard`). Фиксированный бизнес для APK клиента будет в задаче I, сейчас не вводить.
- Загрузка `/me/app-content` через react-query, ключ включает `business_id`. При наличии сохранённого `ETag` слать `If-None-Match`; на 304 использовать сохранённый ответ.
- **Главная:** блок о магазине = `home_store_note_lead` на языке интерфейса (если пусто — нейтральный встроенный текст без названия магазина, например RU «Вы можете потратить баллы по адресу: », KK — переведи и отметь для проверки) + адреса активных магазинов по `sort_order` на языке интерфейса, подчёркнутые. Адрес с `map_url` нажимается и открывает ссылку (`Linking.openURL`, ошибка — существующим способом); без `map_url` — обычный текст. Нет магазинов — блок не показывать.
- **«Мой статус»:** `balance_delay_note` с сервера; пусто — прежний встроенный `balanceDelayNote`.
- Удалить `storeNoteLead`, `storeAddress`, `mobile/src/features/store.ts` и все упоминания «КеремЕт», «In Plaza», `2gis` в `mobile/src` и `mobile/app` (тесты — заменить на данные из моков ответа). Покажи `grep` до и после.
