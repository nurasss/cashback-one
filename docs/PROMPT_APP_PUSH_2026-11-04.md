Иконка — монохромная белая на прозрачном фоне; если подходящей нет, используй `assets/icon-foreground.png` временно и напиши об этом. ### 2. Регистрация устройства

Новый модуль, например `mobile/src/features/push.ts`:

- канал Android `default` (`setNotificationChannelAsync`, важность HIGH, имя RU «Коды и уведомления», KK — переведи, отметь в отчёте для проверки владельцем);
- после входа и при запуске с активной сессией: запрос разрешения (Android 13+), получение **нативного** токена `getDevicePushTokenAsync()` (не Expo push token), `PUT /me/push-token` с `app_id` из `expo-constants`/`expo-application` (сейчас `kz.cashbackone.mobile`, не хардкодить строкой в коде экрана);
- повторная регистрация не чаще раза в сутки, если токен не менялся (сохраняй токен и время в существующем хранилище, не в SecureStore для секретов, если для этого есть обычное); при смене токена (`addPushTokenListener`) — сразу;
- ошибки сети и 429 не показывать покупателю, повторить позже; не логировать токен целиком;
- при выходе (`session.logout()` и `invalidate()` по истечении сессии) — `DELETE /me/push-token` до очистки токенов, ошибку игнорировать, выход не задерживать дольше 3 секунд;
- в demo-режиме push не регистрировать и не запрашивать разрешение.
