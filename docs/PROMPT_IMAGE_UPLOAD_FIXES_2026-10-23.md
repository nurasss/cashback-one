## Что нашёл куратор при независимой проверке

Основа принята: конвертация, поворот по EXIF, удаление EXIF/GPS/ICC, уменьшение, имена файлов, очистка старых файлов и UI-логика работают. Pillow 13.0.0 имеет wheels cp311 для образа `python:3.11-slim`. Admin: 109 passed, typecheck и сборка в порядке.

Но есть дефекты, и часть утверждений отчёта не подтвердилась.

1. **Сбой подключения к хостингу даёт 500 вместо 502.** В `backend/app/services/media_storage.py` вызов `self._create_ftps_client()` в `_sync_put` и `_sync_delete` стоит **до** `try`. Проверено: `FTPSMediaStorage(host="127.0.0.1", port=1, ...).put(...)` бросает голый `ConnectionRefusedError`, то есть 500. Для VPS это самый вероятный реальный сбой: недоступен хост, неверный логин, ошибка TLS.
2. **Полный backend-набор после правок падает:** `1 failed, 347 passed, 36 skipped`. Тест `backend/tests/test_runtime_dependencies.py::test_app_imports_are_runtime_dependencies` сообщает `{'PIL': 'app/services/image_service.py'}`: имя импорта `PIL` не сопоставлено с пакетом `pillow`. В отчёте полный прогон есть только как baseline, после правок — только `test_admin_*`.
3. **`npm run lint` не чистый,** хотя в отчёте написано «чисто»: `admin/tests/image-upload.test.tsx:18:3 error 'locale' is assigned a value but never used`.
4. **Скриншоты не доказывают вёрстку.** Они сняты на временном стенде (`upload-preview.html` / `preview-upload.tsx`, затем удалён), и отчёт об этом не говорит. На `upload-form-ru-320.png`:
   - нет стилей админки (системный шрифт с засечками вместо Roboto);
   - поля обрезаны справа;
   - кнопки «Загрузить файл» не видно;
   - вместо загруженного файла — `data:image/svg+xml`.

   По таким снимкам вёрстку реальной формы оценить нельзя.
5. **Мелкий UI-дефект** в `admin/src/components/ImageUploadField.tsx`. При ошибке загрузки превью `onError` навсегда ставит `display:none` тому же `<img>`, поэтому после новой загрузки или правки ссылки превью не появляется. Кроме того, у превью нет `referrerPolicy="no-referrer"`, а существующий `BusinessLogo` его использует.
