**Упало или неожиданно — СТОП и сырой вывод; без самостоятельных исправлений и повторных мутаций; секреты и персональные данные скрыть.** Сохранить все текущие правки, без APK, commit/push/deploy. Только mobile и отчёт, admin/backend не менять.

Добавить поддержку ограниченной inline-разметки `[текст ссылки](https://example.kz/path)` в общем LinkedText: описание акций и текст уведомлений. По нажатию открывается URL, пользователю виден только текст ссылки. Весь остальной текст/переносы сохраняются. Обычные http/https/www ссылки, добавленные раньше, продолжают работать. Полный Markdown/HTML, картинки и WebView не нужны.

Использовать единый разбор, чтобы URL внутри именованной ссылки не создавал второй вложенной ссылки. В подписи ссылки — обычный текст (RU/KK/Unicode), без HTML и произвольного JSX. Разрешены только безопасные http/https по прежней политике. Некорректную/незавершённую/запрещённую разметку показывать текстом без запуска схем javascript/data/intent/file. Учитывать скобки в URL и обычную пунктуацию, несколько ссылок в одном абзаце, длинные подписи, доступность и обе темы. Ограничить сложность разбора на длинном/невалидном тексте; не добавлять тяжёлый Markdown-пакет без необходимости. Ошибка Linking обрабатывается как прежде.

Системный push остаётся обычным текстовым уведомлением: произвольные кликабельные куски внутри ОС этим не реализуются. Серверный текст и FCM сейчас одинаковые — новую разметку не публиковать в рассылках до согласованного поведения отображения push/старых клиентов.
