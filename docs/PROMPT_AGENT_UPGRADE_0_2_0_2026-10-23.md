4. Версия установленного EXE: `& 'C:\Program Files (x86)\POSCENTER\LoyaltyAgent\CashbackOneAgent.exe' --version` → `0.1.0`. Если без прав не запускается, не обходи: пометь «не проверено до» и попроси владельца в шаге 2.

### 2. Резервная копия [ВЛАДЕЛЕЦ, админ-PowerShell]

5. SHA-256 `.env.service`, `agent_state.db`, `agent_state.key`, `stage0_mapping.json` в оригинале и в копии. Печатать **только хеши**, не содержимое. Хеши должны совпасть.
