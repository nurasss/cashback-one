## Что проверить после обновления — сверх списка 0.2.0

1. `--version` установленного EXE → **0.2.1**.
2. В логе после старта 0.2.1 (ждать **не меньше 12 минут**, минимум два цикла):
   - `Starting POSCENTER Loyalty Agent v0.2.1`;
   - нет `POS service started`, порт 8765 закрыт;
   - **обязательно:** строки `ONE read completed: type=transactions_window, …` за каждый цикл **без ошибок**. Это доказательство, что новая проверка типа даты из 1С пропускает реальные данные.    - строки `ONE read completed: type=cards_snapshot, …` в **новом формате** с `skipped_invalid_barcode=N (empty=…, non_digits=…, too_short=…, too_long=…)`. Перепиши эти числа в отчёт как есть. Ожидается около 7 пропусков. Это только агрегаты — номера карт не искать и не выводить.
